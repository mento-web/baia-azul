# Baía Azul Turismo

Landing page for Baía Azul, a travel agency in Salvador, Bahia.

- Single self-contained page: `index.html` (no build step, no dependencies)
- Palette: "Blue Horizon" (#F1E6CC / #00BDF1 / #009ADD / #0061AA) plus sand (#E8A33D) and navy ink (#16344E), defined as CSS custom properties at the top of the stylesheet
- Photo tiles are CSS/SVG placeholder scenes (`.ph-*` classes), meant to be replaced with real photography
- Contact details in the footer are placeholders
